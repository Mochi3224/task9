ご自身のFirebase Consoleセットアップマニュアル

本アプリは完全実用Google認証・Cloud Firestore連携に対応しています。下の手順に従って設定を行ってください。

1

Google認証の有効化

Firebase Console > Authentication > Sign-in method へ進み、「Google」を有効化します。

2

承認済みドメイン追加

Authentication > Settings > 承認済みドメイン にアプリを公開・実行しているホスト名（例: localhost）を追加します。

3

Firestoreの開始

Firebase Console > Cloud Firestore を作成し、セキュリティルールでログイン済みユーザーへのアクセス権限を許可します。

Firestore セキュリティルール推奨例 (開発・テスト時):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

Firebase接続設定 (firebaseConfig)

Firebase Consoleのプロジェクト設定 >「ウェブアプリ」から取得した firebaseConfig のJSONオブジェクトを入力してください。
